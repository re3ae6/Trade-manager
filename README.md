# Trade Manager V2.8.0

Offline-first Simple + Masaniello trade manager, structured for GitHub Actions and Capacitor Android builds.

## Local development

```bash
npm install
npm run check
npm test
npm run build
```

The `www/` directory is generated by `npm run build` and is intentionally not committed.

## Dependency versions

All `@capacitor/*` packages are pinned to exact versions in `package.json` (no `latest`,
no `^`/`~` ranges), so a build today and a build months from now install the same code.

There is no `package-lock.json` in this repository yet, because it has to be generated
against the real npm registry (this environment could not reach the registry to create
one). To lock installs down completely:

1. Run `npm install` once on a machine with normal internet access.
2. Commit the `package-lock.json` it generates.

`.github/workflows/build.yml` already detects this: it uses `npm ci` automatically once
`package-lock.json` exists, and falls back to `npm install` until then. No further edits
to the workflow are needed after you commit the lockfile.

When you do want to move to a newer Capacitor release later, bump the versions in
`package.json` deliberately and re-test, rather than letting `latest` drift underneath you.


## GitHub Actions → APK

Push to `main`, or open:

**Actions → Build Trade Manager APK → Run workflow**

The workflow:

1. checks out the repository;
2. installs Node.js and Java;
3. installs npm dependencies;
4. runs JavaScript syntax checks and unit tests;
5. builds the web app into `www/`;
6. creates the Capacitor Android project;
7. generates Android app icons from `icons/icon-512.png`;
8. syncs the web assets and Capacitor plugins;
9. builds a debug APK;
10. uploads the APK as the `TradeManager-debug-apk` artifact.

## CSV export

The exported history filename is:

```text
TM.re3a.csv
```

The CSV header starts cleanly with `Session` (without a visible BOM marker), and the final CSV line contains only the signature:

```text
re3ae6
```

## About dialog

The About dialog shows the current app version (`v2.8.0`) and developer signature in a native-looking in-app modal rather than a browser alert.

## Landscape layout

On short phone landscape screens, the three main columns use equal widths with `minmax(0, 1fr)`, while the existing panel borders and internal scrolling are preserved.

## Behavior intentionally preserved

- Simple and Masaniello calculation behavior is treated as a protected contract.
- BE means neither win nor loss and does not consume a Masaniello plan trade.
- Session history persists locally through `localStorage` so closing/reopening the app does not erase it.
- Tapping the session pill starts a new session; holding it for 3 seconds opens the existing confirmation for resetting the session counter.
- Confirmation dialogs use the app's dark custom dialog so the UI stays consistent in the APK.
- The app is built as a personal offline APK through GitHub Actions; the Android project is generated during CI and is not committed.

## Refactor policy

Visual/UI improvements are allowed, but business calculations and trading behavior are not changed without explicit approval.
